## Что является объектом
Человек получет математическую задачу и её решение, сделанное LLM. Человек размечает, верно ли LLM решил задачу. Решение представляет собой последовательность расчетов с краткими пояснениями, финальный ответ отделяется четырьмя решетками: ####.

## Метки и правила
Допустимые значения для label: 
- true — приведенное решение объяснено и корректно, получен верный ответ. Допустимы опечатки, не искажающие смысл решения и значение ответа.
- false — приведенное решение не объяснено или некорректно для данной задачи, или допущены ошибки в вычислениях и значение ответа неверное.
- doubt-true и doubt-false — флаг для случая, когда разметчик не уверен в решении.


## Неоднозначные случаи
При наличии взаимоисправляющих ошибок в вычислениях, считать решение неверным.

При наличии сомнений в корректности собстенной разметки установить флаг doubt.

В ответе модели присутствуют системные рассуждения, заключенные между `<think> </think>`, они помещаются в поле "model_thinking", их за ответ не считаем, модель должна вывести решение с пояснением после этого блока, в "model_answer".

## Для парных сравнений
Без парных сравнений.
